# 📨 Email AI Agent

An automated email classifier, responder, and lead scorer using Mistral AI and OpenRouter.

This project allows you to:
- 🧠 Classify incoming emails into categories
- 📩 Generate auto-replies
- 📈 Score leads based on content
- 📊 View processed leads in a Streamlit dashboard
